# Prácticas Git 2026 🚀

Repositorio de práctica diseñado para dominar el flujo de trabajo con **Git y GitHub** desde nivel básico hasta intermedio utilizando una página web estática en **HTML5 y CSS3**.

---

## 🛠️ Tecnologías y Herramientas
* **HTML5:** Estructura semántica (barra de navegación, tarjeta de perfil y pie de página).
* **CSS3:** Estilos personalizados, diseño de tarjeta con sombras y paleta de colores.
* **Git & GitHub / GitHub Desktop:** Control de versiones local y remoto.

---

## 📂 Estructura del Proyecto

```text
practicas-git-2026/
├── index.html       # Página principal con navbar, tarjeta de perfil y footer
├── estilos.css      # Hoja de estilos del proyecto

├── .gitattributes   # Configuración de atributos del repositorio
└── README.md        # Documentación del proyecto
